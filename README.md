# PROJETS-ALIHO-SALOMON

Dépôt principal regroupant plusieurs projets.

## Projet 01 — NOVAWATCH

Horloge numérique artisanale à 4 chiffres 7 segments, réalisée avec des LED rouges 3 mm, un Arduino Nano, un RTC DS3231, un buzzer passif, quatre boutons et un contour animé composé de LED rouges, vertes et bleues 3 mm.

### Structure

- `NOVAWATCH/README.md` — présentation du projet
- `NOVAWATCH/hardware/WIRING.md` — câblage électrique précis
- `NOVAWATCH/hardware/BOM.md` — liste des composants
- `NOVAWATCH/firmware/` — futur firmware Arduino
- `NOVAWATCH/tests/` — programmes de test
- `NOVAWATCH/docs/` — documentation complémentaire
